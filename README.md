# 📅 財經行事曆 — Financial Calendar

追蹤重大財經事件、財報、總經數據的純靜態行事曆。

## 專案結構

```
financial-calendar/
├── index.html             # 前端檢視器（直接解析 events.md）
├── events.md              # 行事曆資料源（唯一編輯入口）
├── static/
│   └── index.html         # 備份副本（路徑引用不同）
└── README.md
```

## 工作原理

- `index.html` 直接 fetch `events.md`，內建 Markdown 表格解析器，無需後端或構建步驟
- GitHub Pages 自動部署，每次 push 後 1-2 分鐘生效
- 頁面自動隱藏已過去的事件，僅顯示未來事件

## 新增事件

編輯 `events.md`，在對應日期區塊下按格式新增行：

```markdown
### 2026-08-20（四）

| 日期 | 時間 | 事件 | 重要性 | 分類 | 相關標的 | 備註 |
|------|------|------|--------|------|----------|------|
| 2026-08-20（四） | 盤前 08:00 AM ET | **WMT 沃爾瑪財報** | ⭐⭐⭐⭐⭐ | 財報 | WMT | 全球最大零售商 |
```

push 後即更新，無需任何轉換步驟。

## 事件格式說明

| 欄位 | 說明 | 範例 |
|------|------|------|
| 日期 | YYYY-MM-DD（星期） | 2026-08-20（四） |
| 時間 | 盤前/盤後/具體時間 | 08:30 AM ET |
| 事件 | 粗體表示最重要 | **7 月 CPI** |
| 重要性 | ⭐越多越重要（2-5） | ⭐⭐⭐⭐⭐ |
| 分類 | 總經 / 財報 / 解鎖 / 商品 | 總經 |
| 相關標的 | 股票代碼或「全市場」 | AAPL, MSFT |
| 備註 | 補充說明 | 核心CPI 前值 3.5% |

## 財報篩選規則

所有新增嘅美國公司財報，必須**同時符合以下兩項條件**先可以加入行事曆：

### 條件一：大 / 龍頭

市值 ≥ **$300B**，或所屬行業全球 **Top 3**（市佔 > 40% / 掌握獨佔技術）。

### 條件二：可透視行業方向

財報能作為至少一個行業嘅**領先指標 / 晴雨表**，並須喺備註欄標明「透視 XX 行業」。

行業透視分類參考：

| 類型 | 信號意義 | 代表標的 |
|------|----------|----------|
| 供應鏈上游 | 設備/Capex → 下游需求 | ASML、AMAT、LRCX |
| 消費終端 | 消費力 → 宏觀冷暖 | WMT、HD、AMZN |
| 廣告/流量 | 企業投放意願 → 經濟信心 | GOOGL、META |
| 雲/AI 基建 | 科技 Capex 趨勢 | MSFT（Azure）、AMZN（AWS） |
| 金融 | 信貸週期 → 經濟前瞻 | JPM、BAC |
| 能源/商品 | 通脹/供應鏈成本 | XOM、CVX |
